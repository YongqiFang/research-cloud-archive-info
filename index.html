Research Cloud Archive

A personal workflow using a local DVC client to upload and download user-selected research archive files in Google Drive.

How it works

The user chooses the files and runs the DVC client on their own computer. The client uses Google OAuth authorization to access Google Drive, transfer files, and handle the metadata needed for the archive workflow.

The requested Google OAuth scopes are https://www.googleapis.com/auth/drive and https://www.googleapis.com/auth/drive.appdata. The Drive scope permits broad access to Google Drive files; the appdata scope permits access to application-specific data. These permissions are broader than the files selected for a particular transfer.

About this website

This website provides the tool introduction and privacy information. It does not run the DVC client, process OAuth authorization, store OAuth tokens, or upload archive files. It has no analytics scripts, tracking cookies, or forms. GitHub Pages hosts these pages and may process access logs under its own policies.

Read the privacy notice for details about the local client, credentials, retention, and revoking access.

Configuration feedback

Use the public repository Issues for website or configuration feedback. Do not include private research files, credentials, tokens, or OAuth configuration files in an issue.
